# Muhammad Saqib | Portfolio

Welcome to my personal portfolio website! This project showcases my skills, journey, and projects in software development, web development, and game development.

## 🚀 Features
- **Responsive Design:** Works seamlessly across all devices.
- **Smooth Navigation:** Easy-to-use navbar for quick access.
- **Project Showcase:** Displaying detailed descriptions and images of my work.
- **Skill Highlights:** Featuring key technologies I have expertise in.
- **Timeline Section:** Outlining my journey in programming.
- **Contact Section:** Direct links to my GitHub and LinkedIn profiles.
